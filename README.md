#  منصة توصيات التداول (Blogger + Telegram)

هذا المشروع هو تطبيق ويب متكامل لعرض توصيات تداول احترافية، مع واجهة أمامية ديناميكية، خادم خلفي، وربط مع بوت تليجرام لإرسال الإشعارات.

---

## 🌟 الميزات

- **واجهة أمامية ديناميكية:** تم بناء الواجهة باستخدام HTML/CSS/JS وتتصل بالخادم الخلفي لجلب البيانات بشكل حي.
- **الوضع الليلي/النهاري:** تصميم مريح للعين مع إمكانية التبديل بين الوضع الفاتح والداكن.
- **خادم خلفي (API):** تم بناء خادم باستخدام Flask (بايثون) لتقديم بيانات التوصيات والأداء.
- **بوت تليجرام:** بوت متكامل لإرسال التوصيات الجديدة والرد على أوامر المستخدمين (`/last`, `/stats`).
- **قاعدة بيانات وهمية:** استخدام ملف `database.json` لمحاكاة قاعدة البيانات، مما يسهل الاختبار والتطوير.
- **فصل الإعدادات:** تم وضع البيانات الحساسة (توكن البوت) في ملف `config.json` لزيادة الأمان.
- **توثيق شامل:** شرح كامل لهيكل المشروع وكيفية تشغيله.

## 📁 هيكل المشروع

## 🚀 الإعداد والتشغيل

اتبع الخطوات التالية لإعداد وتشغيل المشروع على جهازك المحلي.

### 1. المتطلبات الأساسية

- تأكد من تثبيت [Python 3.8](https://www.python.org/downloads/) أو أحدث على نظامك.

### 2. تثبيت المكتبات

1.  قم بفتح الطرفية (Terminal) في مجلد المشروع.
2.  قم بتثبيت جميع المكتبات المطلوبة باستخدام الأمر التالي:

    ```bash
    pip install -r requirements.txt
    ```

### 3. إعداد ملف التكوين

1.  افتح ملف `config.json`.
2.  تأكد من أن `telegram_token` و `telegram_chat_id` يحتويان على القيم الصحيحة الخاصة بك.

    ```json
    {
      "telegram_token": "YOUR_TELEGRAM_BOT_TOKEN",
      "telegram_chat_id": "YOUR_TELEGRAM_CHAT_ID"
    }
    ```

## ⚙️ كيفية تشغيل المشروع

يجب تشغيل الخادم الخلفي وبوت التليجرام في طرفيتين منفصلتين.

### الخطوة الأولى: تشغيل الخادم الخلفي

- في الطرفية الأولى، قم بتشغيل الخادم الخلفي باستخدام الأمر:

  ```bash
  python app.py
  ```

- سيعمل الخادم على العنوان `http://127.0.0.1:5000`. اترك هذه الطرفية تعمل في الخلفية.

### الخطوة الثانية: تشغيل بوت التليجرام

- في طرفية ثانية، قم بتشغيل سكربت البوت:

  ```bash
  python telegram_bot.py
  ```

- **ملاحظة:** لتشغيل البوت فعلياً، يجب إزالة علامات التعليق من السطر `main()` في نهاية ملف `telegram_bot.py`.

### الخطوة الثالثة: عرض الواجهة الأمامية

- افتح ملف `index.html` في متصفح الويب المفضل لديك (مثل Google Chrome أو Firefox).
- ستقوم الصفحة تلقائيًا بطلب البيانات من الخادم الخلفي وعرض التوصيات والأداء.

## 🔌 واجهة برمجة التطبيقات (API)

الخادم الخلفي يوفر المسارات التالية:

- `GET /api/recommendations`: يقوم بإرجاع قائمة بجميع التوصيات الموجودة في `database.json`.
- `GET /api/performance`: يقوم بإرجاع سجل الأداء التاريخي للصفقات.
